WordMaster v0.1.0

Windows 64 位 · Ubuntu 24.04 x64

Windows 下载 Ubuntu 下载
Windows 百度网盘提取码已包含在链接中；Ubuntu 安装包位于 GitHub Releases。

系统要求

  • Windows 64 位；需要 Microsoft Edge WebView2
  • Ubuntu 24.04 x64 桌面系统
  • AI 功能需要网络与用户自己的 API Key

Windows 版在 Windows 11 验证；Linux 版通过 Ubuntu 24.04 自动安装与启动检查。

安装方式

  1. Windows：下载百度网盘 ZIP、解压，运行其中的 WordMaster_Setup.exe。
  2. Ubuntu：下载 .deb 后执行 sudo apt install ./WordMaster_0.1.0_ubuntu24.04_amd64.deb。
  3. 首次使用 AI 功能时，在设置中填写自己的 API Key。

学习数据保存在当前用户的本机数据目录。

隐私与数据

词汇进度、复习记录与历史对话保存在本机，不会自动同步到 WordMaster 服务器。Windows 的用户 API Key 存于系统凭据管理器；Ubuntu 版通过系统密钥环（keyring，通常是 GNOME Keyring）保存，密钥服务不可用时会提示保存失败。

只有主动使用 AI 导师、AI 阅读等功能时，相关问题和必要上下文才会发送至所配置的 AI 接口。查看完整使用协议
